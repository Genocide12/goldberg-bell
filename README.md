# Машина Голдберга — интерактивная физическая модель

> Живая машина Голдберга в браузере: **собственный физический движок твёрдых тел**
> (SAT-контакты, трение Кулона, шарниры, sequential impulses с warm start,
> позиционная стабилизация — 240 Гц) и 3D-визуализация на чистом Canvas 2D.
> Один самодостаточный HTML-файл: без библиотек, без CDN, без сборки.

**Открыть модель:** <https://genocide12.github.io/goldberg-bell/>

## Что это

Шесть физических звеньев, ни одного анимационного ключа — только гравитация,
столкновения и трение:

1. **Горка-1 (30°)** — стальной шар (1 кг) скатывается с высоты 1.55 м
2. **Столы** — скользкий участок (μ=0.1) разгоняет шар, «липкий» (μ=0.9) держит домино
3. **8 домино** — волна опрокидываний; последнее домино сбрасывает стеклянный шар (0.5 кг) с края
4. **Горка-2 (20°) + жёлоб** — разгон; с обреза жёлоба шар летит **баллистически**
5. **Молоток-маятник** — шар бьёт в голову, маятник (0.3 кг) качается на шарнире
6. **Колокол** — молоток бьёт в юбку; колокол (0.9 кг) качается на шарнире и звонит
   в два боковых страйкера — физически: каждое касание = удар со своей скоростью

## Интерактив во время опыта

- **Запуск** (или Enter) — сброс и старт; **Space** — пауза; **R** — сброс
- **Перетаскивание тел мышью** — любое тело можно поймать, увести и бросить прямо
  во время движения (в паузе — расставить сцену руками)
- **Пустое место** — вращение камеры, **колесо** — масштаб
- **Панель параметров** (справа) — гравитация, упругость, наклоны обеих горок,
  массы всех тел, трения всех поверхностей: действуют **мгновенно**, на лету
- **Звук** — синтез в WebAudio: каждое касание страйкера даёт «динь» с громкостью
  по силе удара (vn0 из солвера), удар молотка — низкий «бонг»

## Технические решения (проверены тестами)

- Динамика плоская (плоскость X-Z) — вся машина планарна, поэтому 2D-движок
  даёт те же траектории, что 3D-солвер, при втрое меньшей стоимости контактов;
  визуализация при этом полноценная 3D-перспектива с орбитой камеры
- Warm start импульсов между субшагами + «возраст» контакта: отскок включается
  только у свежих касаний — убаюкивание вечных пар (молоток×колокол)
- Проникновение убирает отдельный **позиционный проход** (≤4 мм/субшаг),
  не добавляя энергии в скорости — никакого «насоса» раскачки
- Трение пары = √(μ₁·μ₂) (комбинированное, как в Bullet): «скользкий для шара,
   липкий для домино» на одном столе
- Сопротивление качению включается только когда точка касания уже не скользит —
  шары не едут вечно, но и не тормозят в полёте

## Проверка

Автотесты без браузера (Node): прогон опыта от запуска до покоя, 11 проверок —
домино 8/8, звон, амплитуда колокола, успокоение, шары на местах:

```bash
node scripts/test_model.js
```

Смоук-тест в реальном браузере (Playwright + Chromium): загрузка, запуск до звона,
живые параметры, слайдеры, пауза, drag тел, орбита, сброс — 12 проверок:

```bash
node scripts/smoke_browser.js
```
