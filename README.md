# Машина Голдберга: от шара — до звона колокола

> Полностью физическая машина Голдберга в **Blender 4.5 LTS** (Bullet Physics, rigid body).
> Ни одного ключевого кадра движения — только гравитация, столкновения, трение
> и три шарнира. Финал: молоток-маятник бьёт в латунный колокол, тот качается
> на 34° и звонит в два боковых страйкера: *бонг… динь… динь*.

**Сайт проекта:** <https://genocide12.github.io/goldberg-bell/>

## Цепочка (6 звеньев, 240 кадров @ 24 fps)

| # | Звено | Что происходит | Кадры |
|---|-------|----------------|-------|
| ① | Горка-1 (30°) | Стальной шар (⌀200 мм) скатывается с высоты 1.55 м | 6+ |
| ② | Столы + домино | Шар катится по скользкому столу (μ=0.1) и влетает в 8 домино на «липком» столе (μ=0.9) | 30–43 |
| ③ | Срыв шара2 | Последнее домино сбрасывает стеклянный шар (m=0.5) с края стола | 36 |
| ④ | Горка-2 (20°) + жёлоб | Шар2 скатывается и летит **баллистически** с обреза жёлоба | 40–51 |
| ⑤ | Молоток-маятник | Шар2 бьёт молоток (L=0.8 м) в голову; тот качается на шарнире | 51–59 |
| ⑥ | Колокол | Молоток бьёт в юбку колокола (профиль вращения, стенка 28 мм); колокол звонит в 2 страйкера | 59+ |

Телеметрия финального прогона: удар молотка — кадр 59, максимум угла колокола —
34°, страйкеры получают 168 соударений за 6 секунд звона.

## Структура

```
scripts/
  goldberg4.py        # сцена + физика + телеметрия (--phase=save пишет .blend)
  render_goldberg.py  # материалы/свет/камера + рендер (--phase=keyframes|anim)
  bell_sound.py       # синтез звука колокола из телеметрии (26 событий)
  make_video.py       # ffmpeg: ключевые кадры + wav → mp4
  build_site.py       # генерация сайта GitHub Pages (index.html)
site/                 # источник GitHub Pages (index.html + media/)
goldberg_physics.blend  # сцена с запечённой физикой (point cache)
telemetry.json          # покадровые позиции/углы/скорости всех звеньев
media/                  # ключевые кадры, bell_sound.wav, goldberg_bell.mp4
```

## Воспроизведение

Нужен Blender 4.5 (любой билд, `blender` в PATH) и Python 3 + ffmpeg:

```bash
# 1. Симуляция + телеметрия + .blend  (~1 мин)
blender -b -P scripts/goldberg4.py -- --phase=save

# 2. Материалы/свет/камера; 6 ключевых кадров  (~8 мин, CPU)
blender -b work/goldberg.blend -P scripts/render_goldberg.py -- --phase=keyframes

# 3. Звук колокола из телеметрии
python3 scripts/bell_sound.py

# 4. Видео: кадры + wav → mp4
python3 scripts/make_video.py

# 5. Сайт
python3 scripts/build_site.py
```

`work/goldberg.blend` можно просто открыть в Blender и нажать Alt+A —
физика запечена в point cache и проиграется как анимация.

## Технические находки (проверено экспериментально)

- **Ось HINGE = локальная Z хост-объекта констрейнта** (пивот — его позиция).
  Чтобы ось стала мировой Y, якорь поворачивается на 90° по X.
- **Центр масс rigid body = origin объекта.** Молоток: origin в голове, шток вверх
  к пивоту — маятник качается сам под гравитацией.
- **collision_margin**: дефолт 0.04 м создаёт фантомные контакты при зазорах < 4 см.
  Везде 0.004.
- **Знак наклона**: `rot=(0, +A, 0)` опускает +X-конец плоскости вниз (шар едет в +X).
- **Комбинация трений ~√(μ₁·μ₂)**: домино стоят на «липком» столе (падают, а не
  скользят), а шар по нему же проходит скользко (μ шара 0.05).
- **Стабильность солвера**: substeps=10, solver_iterations=60; маятники без sleep,
  остальные тела засыпают при 0.08 м/с.
