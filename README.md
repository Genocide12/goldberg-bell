# Машина Голдберга — живая физика на готовых движках

> Интерактивная машина Голдберга в одном HTML-файле на **готовых проверенных
> библиотеках**: физика — [Rapier 0.21](https://rapier.rs) (Rust → WebAssembly,
> игровой физдвижок), рендер — [three.js r187](https://threejs.org) (PBR-материалы,
> мягкие тени, HDR-окружение), камера — OrbitControls. Без CDN — все библиотеки
> лежат локально в `vendor/` и работают офлайн.

**Открыть модель:** <https://genocide12.github.io/goldberg-bell/>

## Настоящие предметы (реальные плотности и размеры)

| Предмет | Размеры | Масса | Материал |
| --- | --- | --- | --- |
| Стальной шар | Ø80 мм | 2,1 кг | сталь 7850 кг/м³ |
| Домино ×8 | 190×50×8 мм | 58 г | МДФ 720 кг/м³ |
| Стеклянный шарик | Ø40 мм | 84 г | стекло 2500 кг/м³ |
| Молот-маятник: голова 160×320 + палка | — | 150 г | сосна ~520 кг/м³ |
| Латунный колокол | Ø95 мм | 160 г | латунь 8500 кг/м³ |
| Страйкеры ×2 | Ø24 мм | 69 г | латунь |

## Цепочка (чистая физика 240 Гц, ни одного анимационного ключа)

1. Стальной шар срывается с горки-жёлоба (22°) и разгоняется до ~1,7 м/с
2. Шар валит первое домино в верхнюю треть плашки — волна проходит 8/8
3. Последняя плашка выпихивает стеклянный шарик с обрыва стола
4. Шарик катится по жёлобу (13°) и бьёт в молот-маятник
5. Молот качается и бьёт в юбку латунного колокола
6. Колокол раскачивается и звенит о два боковых страйкера;
   громкость «дина» — от скорости колокола в момент касания

## Интерактив

- **▶ Запуск** (Enter) — сброс и старт; **Space** — пауза; **R** — сброс; 🔊 — звук
- **Перетаскивание мышью** — любое тело можно поймать и перебросить,
  в том числе во время опыта (drag-and-throw с сохранением скорости броска)
- **Пустое место** — орбита камеры (OrbitControls), **колесо** — масштаб

## Технологии

- **Rapier** (`rapier2d-compat`, WASM 2,3 МБ) — твёрдые тела, шарниры-«нити»,
  CCD для быстрых шаров, трение Кулона, плотности реальных материалов
- **three.js** — PBR: `MeshStandardMaterial`/`MeshPhysicalMaterial` (прозрачное
  стекло с transmission), процедурные текстуры дерева и дощатого пола на Canvas,
  мягкие тени 2048², ACES-тонемаппинг, `RoomEnvironment` для отражений металла
- Звук — WebAudio-синтез; события контактов опрашиваются напрямую из солвера
- Один самодостаточный HTML + локальный `vendor/` (~7,6 МБ, всё офлайн)

```bash
node scripts/smoke_rapier.js   # интерактив (кнопки, drag, камера, пауза, сброс): 9 проверок
```

## Структура

```
index.html                  # страница + вся логика (физика, рендер, звук, UI)
vendor/                     # three.js r187, rapier2d 0.21 (wasm в base64), примеры three
scripts/test_rapier.js      # автотест физики
scripts/smoke_rapier.js     # смоук-тест интерактива
scripts/build_vendor.py     # пересборка vendor из npm-пакетов и примеров three.js
```
