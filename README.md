# Машина Голдберга — длинная цепочка на 28 секунд (cannon-es)

Развитие v3 по запросу «очень длинная цепочка на 25 секунд»: два яруса,
две волны домино (8 + 10), два маятника и 2.3-метровый жёлоб-регулятор
темпа. Настоящие плотности (сталь 7850, латунь 8500, сосна 600 кг/м³),
трения по парам материалов, шаг 1/120 с.

## Хореография (~28 с)
1. стальной шар Ø32 (135 г) скатывается с горки 20° → **волна① из 8** (t≈5 c)
2. дом7 бьёт маятник① (v=0.11) → его голова на взмахе **сбивает шарик② Ø16**
   с тумбы (v=0.78, t≈4.9 c)
3. шарик② катится по **жёлобу 2.26 м** (3°) — регулятор темпа
4. срез жёлоба над полосой: шарик② бьёт дом8 в грудь (v=0.91, t≈10.5 c)
   → **волна② из 10** ложится за t≈23.5–28 c
5. дом17 бьёт маятник②-боёк (v=0.55) → голова на взмахе 13° ударяет
   **латунный колокол Ø58** → 🔔 ЗВОНА (t≈28.0 c)

Архитектура «один источник правды»: `machine.js` строит и физику, и спеку
рендера (`m.spec`) — графика не может разойтись с физикой. Звук — в момент
удара (события из движка → WebAudio-синтез).

## Проверки
- `node scripts/tune_headless.js` — headless-физика: 9/9 ×3 прогона (звон 28.05 с)
- `node scripts/bench_domino.js`, `bench_v4.js` — бенчмарки узлов
- `node scripts/smoke_cannon.js` — браузерный смоук: 9/9

## Файлы
- `index.html` — страница (three.js, PBR, тени, drag мышью, звук ударов)
- `machine.js` — физическая модель (единственный источник геометрии)
- `vendor/` — локальные сборки three/cannon-es (работает без сети)
