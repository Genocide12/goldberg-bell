# Машина Голдберга — «шоу» (v6, cannon-es)

По просьбе «разнообразить: не только шарик-домино-колокол».

## Новые звенья (всё честной физикой)
1. **КСИЛОФОН-ЛАДЫ**: 5 латунных полосок врезаны в пол жёлоба
   (3.50..4.38). Шарик② пробегает их — звучат 5 нот D-E-F#-A-B
   (6.6-7.8с, интервал 0.3с — ровная гамма). Лады не принадлежат
   физике (1 мм — контакт убил бы ход шарика): нота = честное
   событие пересечения отметки (step-трекер в machine.js).
   Двенадцать контактных прототипов (колышки-плинко, качалка,
   катапульта-рычаг, снаряд, клавиши, «мостовая», маятниковые
   колокольчики) отвергнуты: стеклянный шарик 2.3 г в cannon-es
   теряет ход от любого касания, а волна ломается о препятствия.
2. **ФИНАЛИСТ-120**: последняя плашка волны② — двойная (120 мм,
   18.8 г). Её кончик дотягивается дальше обычной и хлещет юбку
   колокола (проверенная связка «кончик хлещет», v=0.62).
3. **Кино-камера**: авто-планы за действием (старт → волна① →
   жёлоб с нотами → волна② → финал), колесо/драг отключают (кнопка 🎬/клавиша C).
4. Счётчик HUD: волны + 🎵 ноты + 🔔; аудио нот — латунный «дзынь»
   на частотах D4 E4 F#4 A4 B4.

## Хореография (~13 с)
шар с горки → волна① 8 плашек (0.12 с/шт) → хлыст дом7 по шарику②
(v0.68) → жёлоб: 5 нот (6.6-7.8) → срез → старт волны② (v0.7) →
34 плашки → финалист-120 хлещет колокол → 🔔 12.75 с

## Проверки
- `node scripts/tune_headless.js` — 11/11 × 3: волны 8/8 и 34/34,
  5 нот, звон 12.75 с, без мостов, сана
- `node scripts/timeline_v5.js` — таймлайн с каузальностью
  (дрейф шарика② до запуска 0.0000 м)
- `node scripts/smoke_cannon.js` — браузерный смоук (см. примечание)

## Известный флажок
Смоук в headless-браузере фыркает: в ~50% прогонов волна① замирает
на 4-й плашке (в headless-физике Node — стабильно 3/3). Похоже на
особенность кадровой упаковки шагов в тест-режиме (pace 2, cap 240).
Прод-страница работает нормально при обычном 60fps.

Единый источник правды: `machine.js` (физика + спека рендера).
