# Машина Голдберга — живая физика с натуральными предметами

> Интерактивная машина Голдберга в одном самодостаточном HTML-файле:
> **собственный физический движок твёрдых тел** (SAT-контакты, трение Кулона,
> шарниры, sequential impulses с warm start, позиционная стабилизация, 240 Гц)
> и 3D-визуализация на чистом Canvas 2D. Без библиотек, без CDN, без сборки.
> Никаких ползунков и настроек — только реальные предметы, реальная физика.

**Открыть модель:** <https://genocide12.github.io/goldberg-bell/>

## Настоящие предметы (реальные плотности и размеры)

| Предмет | Размеры | Масса | Материал |
| --- | --- | --- | --- |
| Стальной шар | Ø80 мм | 2,10 кг | сталь 7850 кг/м³ |
| Домино ×8 | 190×50×8 мм | 58 г | МДФ 720 кг/м³ |
| Стеклянный шарик | Ø40 мм | 84 г | стекло 2500 кг/м³ |
| Молот-маятник: голова + палка | 240×320 + Ø10×160 | 150 г | сосна 520 кг/м³ |
| Колокол | Ø95 мм | 160 г | латунь 8500 кг/м³ |
| Страйкеры ×2 | Ø24 мм | 69 г | латунь |

Трения — комбинированные по Кулону (μ пары = √(μ₁·μ₂)): полированный жёлоб
(μ 0.02) разгоняет шарик, «липкая» зона домино (μ 0.5) держит волну.

## Цепочка (всё — чистая физика, ни одного ключа анимации)

1. Стальной шар срывается с вершины горка-жёлоба (22°) и разгоняется
2. Шар валит первое домино (удар приходится в верхнюю треть плашки) — волна 8/8
3. Последнее домино выпихивает стеклянный шарик с наклонного края стола
4. Шарик катится по длинному жёлобу (13°) и бьёт в молот-маятник
5. Молоток качается и бьёт в юбку латунного колокола
6. Колокол раскачивается и звенит о два боковых страйкера —
   каждое касание даёт «динь», громкость по силе удара (WebAudio)

## Интерактив

- **▶ Запуск** (Enter) — сброс и старт; **Space** — пауза; **R** — сброс
- **Перетаскивание мышью** — любое тело можно поймать, увести и бросить,
  в том числе прямо во время движения (в паузе — расставить сцену руками)
- **Пустое место** — вращение камеры, **колесо** — масштаб
- Звук — синтез в WebAudio из телеметрии контактов (vn0 из солвера)
