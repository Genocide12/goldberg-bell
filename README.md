## v7 — ГОРОД ИЗ КАРТ (новинка)
**Открыть: [index_v7.html](https://genocide12.github.io/goldberg-bell/index_v7.html)**

По просьбе «домино заменить на игровые карты + огромные пирамиды, которые
красиво падают по цепи». Машина построена ТОЛЬКО из игральных карт —
292 карты (покер 88×63 мм, 920 кг/м³, 3.1 г):

щелчок по первой карте → **волна A** (12 карт) — веер-камертон рушит
**Башню «Маяк»** (5 этажей Λ-домиков) → **волна B** (36) — веер рушит
Λ-домик → **волна C** (36) — веер рушит **Башню «Гранд»** (4 этажа) →
**волна D** (36) — веер рушит Λ-домик → камертон валит **улицу-замок**
из 8 Λ-домиков (домики рушат друг друга) → последний домик падает на
**ГИГАНТ-ПИРАМИДУ [8-7-6-5-4-3-2-1] = 108 карт** → обвал валит
**КАРТУ-КОРОЛЬ** на вершине: «👑 КОРОЛЬ ПАЛ» (~21 c, всё шоу ~35 c).

### Секрет стойкости карт (физика, не анимация)
Карта 0.3 мм на ребре не стоит в дискретном солвере (падает за 0.01 с —
проверено стендом). Решение: мир не усыпляет тела (`allowSleep=false`),
каждая карта заморожена `body.sleep()` и стоит идеально; **любое касание
будит тело** — дальше честная физика. Дополнительно «пробуждение по рухнувшей
опоре»: движение в 40 мм под спящим будит его (иначе король и верхние этажи
башен висели бы в воздухе без касания). Темп волны настоящий — 0.10–0.14
с/карта. Прогоны детерминированы: 3/3 идентичны; повторный запуск после
сброса даёт ту же цепочку.
