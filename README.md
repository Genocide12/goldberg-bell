# Машина Голдберга — реальная физика (cannon-es)

Переписано на честный 3D-физдвижок **cannon-es**: настоящие плотности
(сталь 7850, латунь 8500, сосна 600 кг/м³), реальные коэффициенты трения
и восстановления для каждой пары материалов, шаг 1/120 с.

Цепочка: стальной шар Ø32 (135 г) скатывается с горки 20° → бьёт первую
плашку → волна из 6 домино (шаг 35 мм = 0.4h) → последняя плашка бьёт
маятник-молот (v≈0.55 м/с) → голова молота на взмахе ~16° ударяет
латунный колокол Ø58 на подставке (800 г) → звон.

Архитектура «один источник правды»: `machine.js` строит и физику, и
спецификацию рендера (`m.spec`) — графика не может разойтись с физикой.
Звук — в момент удара (события приходят из движка), синтез WebAudio.

## Проверки
- `node scripts/tune_headless.js` — headless-физика: 6/6 проверок ×3 прогона
- `node scripts/bench_domino.js` — бенчмарк волны (итерации солвера, шаг)
- `node scripts/smoke_cannon.js` — браузерный смоук: 9/9

## Файлы
- `index.html` — страница (three.js, PBR, тени, drag мышью)
- `machine.js` — физическая модель (единственный источник геометрии)
- `vendor/` — локальные сборки three/cannon-es (без сети)
