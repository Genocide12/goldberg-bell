# Машина Голдберга — «по-настоящему» (v5, cannon-es)

По жалобе: «второй шарик катится сам по себе при старте, домино падают
медленно и не по-настоящему».

## Что было не так
- Шарик② стоял на **наклонной** тумбе — сам съезжал до всякого домино.
- Домино были игрушечными: 88×44×10 мм (в 2.2 раза выше настоящих),
  4.6 г, контакты «резиновые» (relax 3, μ граней 0.10) — каскад
  полз 0.3-0.8 с/плашка, плашки зависали клиньями.

## Что сделано (каждая цифра — из стендов)
1. **Реальные домино**: 60×28×8 мм, бук 700 кг/м³ → 9.4 г; шаг 0.65×h;
   подошва μ 0.80 (опрокидывание у основания, не скольжение).
2. **μ граней дом-дом 0.10 → 0.01**: трение скольжения при нажиме
   лежащей плашки съедало энергию падения. Стенд перебрал шаг/отскок/
   трение: 0.61 → **0.12 с/плашка**, уклад плоский 74-90°.
3. **Шарик② стоит мёртво**: пьедестал у края яруса; дрейф до запуска
   **0.0000 м** (замер по кадрам). Запускает его только физическое
   падение дом7: кончик дуги (θ≈52°) хлещет шарик радиально —
   v=0.68 м/с (проверено свипом 8 позиций: клин/выброс убраны).
4. **Молот-«ползун» упразднён**: кончик дом53 бьёт колокол напрямую
   (v=0.36) — исчезла 11-секундная вялость финала.
5. Шар① — орех Ø24, 5 г: триггер, а не бульдозер.

## Хореография (~15 с)
шар с горки (1.9) → волна① 8 плашек 0.12 с/шт (2.1-2.9) → кончик
дом7 хлещет шарик② с пьедестала (2.88, v 0.68) → жёлоб 8°+0.4° (3-9)
→ удар дом8 (8.9, v 0.71) → волна② 46 плашек (9.3-14.8) → кончик
дом53 хлещет колокол (14.78, v 0.36) 🔔

## Проверки
- `node scripts/tune_headless.js` — 10/10 × 3: обе волны падают
  полностью, без мостов (15-40°), звон 14.78 с в окне 13-18 с
- `node scripts/timeline_v5.js` — полный таймлайн с каузальностью
- `node scripts/tune_cascade.js` — стенд каскада (поиск μ-рычага)
- `node scripts/smoke_cannon.js` — браузерный смоук 9/9

Единый источник правды: `machine.js` строит физику и спеку рендера.
