# Машина Голдберга — цепочка на 22 секунды (cannon-es)

Развитие по жалобе «домино тяжёлые, не всегда падают»: волна висела
«клином» по 10-15 секунд — плашки стояли наклонённые друг на друге
и ползли по градусу в секунду.

## Что изменилось (найдено изолированным стендом «клина»)

- **Контакты домино жёстче и резче**: `contactEquationStiffness 1e8` +
  `contactEquationRelaxation 2` (было 1e7/3). Клин из двух плашек падает
  за 0.23 с вместо 2.3 с; волна — 0.1-0.4 с/плашка вместо 1-16 с.
  Restitution дом-дом 0.35 → 0.12: без рикошета (высокий отскок
  «холодно сваривал» плашки в клин).
- **Наклонная тумба 20°** для шарика②: молот① лишь черкает по шарику
  (передача «молот→шарик на тумбе» в cannon-es даёт максимум 0.23 м/с —
  проверено 4 массами и 2 зазорами), но наклон tan20 > трения покоя —
  шарик скатывается сам и сразу уезжает в жёлоб.
- Волна② удлинена до 26 плашек — темп честный, без вязких пауз.

## Хореография (~22 с)
1. шар Ø32 скатывается с горки → **волна① из 8** (3.5 с, звонкий каскад)
2. дом7 бьёт маятник① (0.37) → голова черкает шарик② на наклонной тумбе
3. шарик② съезжает (0.45 м/с) и катится по жёлобу 2.6 м (3°)
4. удар в грудь дом8 (1.13 м/с) → **волна② из 26** (6.3–16.2 с)
5. дом25 бьёт маятник②-боёк → **🔔 колокол** на 22.4 с

## Проверки
- `node scripts/tune_headless.js` — 11/11 × 3 прогона: обе волны падают
  полностью, без мостов (20-55°), звон 22.4 с в окне 18-28 с
- `node scripts/tune_domino.js` — стенд клина/волны (поиск рычага)
- `node scripts/smoke_cannon.js` — браузерный смоук 9/9

Единый источник правды: `machine.js` строит физику и спеку рендера;
графика не может разойтись с физикой. Звук — в момент удара (события
движка → WebAudio).
